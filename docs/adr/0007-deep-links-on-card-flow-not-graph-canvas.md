# 驾驶舱深链落在卡片流，不引入可平移缩放的图画布

v0.8 计划书假设存在可平移缩放的图编辑器画布并要求"画布自动居中聚焦动画"；实际 Canvas 是拓扑卡片流（v0.7 focus-flash）。决定：深链以卡片流实现——`?focus=` 滚动并闪烁匹配的链路卡片、`?traceId=` 标注现场、`?mode=diff` 直达 delta 视图，不新建 SVG 图布局引擎。理由：图画布是独立大工程（布局、视口动画、可达性），其收益（大图浏览）与深链场景（单链路验真）不匹配；卡片流 + focus-flash 已承载 Issue 12 的聚焦语义。代价：几百跳的全局拓扑浏览体验停留在 delta mermaid 图，不提供画布级导航；若未来引入图画布，深链参数契约（focus/mode/traceId）保持不变。
