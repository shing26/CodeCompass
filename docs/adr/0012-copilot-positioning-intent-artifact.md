# Copilot 定位升级：只读架构雷达与演进顾问，Intent→Artifact 交互模型

本 ADR 细化 ADR-0001 的产品方向而不改变它：CodeCompass 面向"接手陌生代码库"的开发者，做架构雷达（全景概览、调用拓扑、物理证据）与演进顾问（落位建议、下线推演、风险边界），坚决不做低配编辑器智能体——不写回源码、不接运行时、不追 IDE 补全特性，把"证据与导航"做到极致。交互模型定为 Intent→Artifact：废除通用聊天气泡，用户给一个意图，智能体单次产出高密度工件卡（定位节点 + 拓扑图谱 + 落位清单 + 风险 Checklist），不逐步反问；会话历史呈现为工件流（Artifact Stream），严格按 (repoId, commit) 物理隔离（承接 ADR-0010 四元组的时空一致性），不做跨仓库全局记忆库；对工件卡的追问视为一次新的意图输入。Incident Copilot（ADR-0011）收编为推演台内的专用堆栈诊断控制台，边界不变，不再是通用聊天入口。理由：目标用户是调查型开发者，价值在单次交互的信息完成度与可校验性；气泡式逐步对话稀释密度，且与零幻觉合约要求的工件化产出形态重复。代价：失去渐进式引导，新用户引导完全依赖看板与 Quick Tour 承载。否决的替代方案：整段移除对话输入（调查型用户的多步追问成本过高，如"看完诊断卡再要爆炸半径"）；保留通用聊天 + 全局记忆（违 ADR-0001 本地优先与本 ADR 边界四）。未决事项（grilling 收尾中）：MCP 工具对演进类问法的补齐（Issue 25）。已裁决随附 ADR：图谱几何引擎垄断（0013）、Pattern Ingestion 证据化 + 近邻仲裁（0014）、演进工作台自由文本意图入口 + Issue 24/25 打包（0015）。
