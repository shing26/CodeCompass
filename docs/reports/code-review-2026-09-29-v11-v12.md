## 发现与处置（逐条）

### P1（已修复）

1. **reindex / clone 两条 fire-and-forget 仍「吞掉即僵尸」**（代码轴；`routes/repos.ts:187/:264` 旧实现 `.catch(() => {})`）：`indexRepo` 的 pre-try 序言（fs.stat/upsert）会 reject（典型：导入后目录被删/改名/网络盘卸载再点重新索引）→ 行永远停在 `indexing`，DELETE/reindex 全 409，只能重启进程。
   **处置**：抽 `guardIndexFailure(deps, repoId, error)` 唯一实现（含 catch 自身自保），POST/reindex/clone 三处统一——票 03 建立的僵尸防线补齐到全部入口。

### P2（已修复）

2. **frozen 门 fail-open：整份 frozen 摘要被删静默放行**（spec 轴实测：删 `frozen/self.json` 后门仍 PASS）；**结构畸形裸抛**（缺 `filePath` → 未捕获 KeyError 丢门禁输出）；**entry 级白名单缺失**（entry 内注入 `measuredAt` 仍 PASS）。
   **处置**：`check_precision_frozen` 三修——① frozen↔verdicts **文件名集合双向相等**（空目录也红）；② 结构畸形记账 FAIL 不裸抛；③ entry 级白名单与必需键校验。**会红验证**：整文件缺失 / entry 缺键 / entry 注入易变字段 三态全红，复原绿。
3. **MCP `index_repo` 僵尸防线未自保**（与 HTTP twin 不对称；db 已关时 catch 内再抛 → unhandled）。
   **处置**：`mcp/repoqa-mcp.ts` catch 内 `updateRepoStatus` 加 try/catch，同款注释。
4. **`pollRepoReady` 超时不抛 + 高耗用例无超时档**（代码轴实测：导入链路用例本机 1.3–2.8s，慢机 2x 越过 vitest 默认 5s；旧实现返回 null 被调用点丢弃，报错指向下游）。
   **处置**：超时改为**抛错携带 last-status**；`repoqa-http / repoqa-events / repoqa-commit-anchor` 三文件 `vi.setConfig({ testTimeout: 15_000 })`。
5. **折叠切点切半 `[cite: N]`/代理对**（`ChatView.tsx` 直 slice 实证推演）。
   **处置**：`foldAt()` 安全回退——代理对保护 + 回退到最近换行/空格（120 字符窗）+ 丢弃尾部残缺 `[cite:` 前缀。
6. **检索分区陈旧命中/失败伪装空**（query 变化不清旧 hits；catch 设 `[]` 冒充「无命中」）。
   **处置**：query 变化即清 hits；失败走独立 `chunkError` 态（`scan-search-error`）。
7. **体检面正文渲染引擎英文 detail**（"0 static callers" 等，筛 v0.30 中文纪律）。
