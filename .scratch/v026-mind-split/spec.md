# v0.26-A Spec：问答/演进口心智分离（问现状 / 要方案）

> grill session 2026-09-10 产出。上游承诺：`.scratch/chat-merge/issues/07` 排期预留 A；票 15 out-of-scope 的移交物。
> 决策编号 Q2–Q8 对应访谈轮次；术语已在 `CONTEXT.md` glossary 钉扎（问现状/要方案、Plan Digest、惯例归一）。

## 问题

六 tab 稳定后（8ac9bea 改名轮 + v0.25），「架构问答」与「规范演进」两入口的用户可辨度不足：读口（问现状）与方案口（要方案）的产出物在四处漂移命名（N1–N11），且 chat 答案流内嵌「拆除计划+勾选框」卡片，事实上的方案输出与"只读咨询"定位正面冲突。票 15 只修了失实名，本票做**心智重排**。

## 裁决（设计决策表）

| # | 决策 | 内容 |
|---|------|------|
| Q2 | 定位句 | 问答=**问现状**（结论皆代码事实）；演进=**要方案**（落位建议+风险清单）；「**引擎只读，改动由你执行**」为两入口共享底线，在引导/产出物常驻。「读侧/写侧」仅内部语言，禁入用户可见文案。 |
| Q3 | PlanCardView | 保留重塑为「**方案摘要**」（Plan Digest）：头部常驻底线声明；CTA「在规范演进中展开 →」跳 evolve。问答口方案输出不被阉割，成为两视图的桥。 |
| Q4 | 冲突语系归一 | 「规范/约定/模式」三分归「**惯例**」（惯例嗅探/惯例清单/惯例冲突）；「规范演进」**视图名保留**（"规范"=产品品牌词，不再参与措辞族）；tooltip「检查代码约定冲突」→「惯例冲突」。glossary Pattern Ingestion 括注改「惯例嗅探」。 |
| Q5 | 产出物命名 | 集合词只留「**工件卡**」（Workbench Cards）；卡型名=glossary 四段（惯例清单/落位表/死代码清单/风险 Checklist）；「推演卡」退场，「推演」降为纯动词（开始推演/追加推演/第五阶段名）；「变更清单」→「落位表」（EXTEND 语境作「落位表·变更」小节）。 |
| Q7 | 引导不对称保留 | 问答=示例卡（STARTER_CARDS），演进=①②③步骤（ScenarioGuide）——交互形态本身表达"咨询轻/方案有流程"，**不统一**。「变更风险评估」starter 合法保留（问的是影响面事实，非方案）。 |
| Q8 | 入口与遗留 | Sidebar `Evolution`→「规范演进」，不新增 chat 侧栏入口；Dashboard「提问」按钮**只改名「查调用链」**，接线不动（setView('topo')+trace 行为本来就对）；画布空态改「两动词+四设施」结构。 |

## 逐面改造清单（实现票的靶面）

1. **TopBar.tsx TABS**（L55/L58）：chat title → 「问现状：架构、链路、风险都基于代码事实，结论可逐条 [cite] 查证」；evolve title → 「要方案：给改动意图，产出落位建议与风险清单；引擎只读，改动由你执行」。
2. **ChatView.tsx**：L326「架构问答助手」→「架构问答」（去"助手"，入口名唯一）；空态引导句补底线声明（L366 现句「来自代码事实」保留，追加「引擎只读，改动由你执行」）；L358「新对话 ·」→「新会话 ·」（会话/对话混用收敛，"会话"是 canonical，表名 chat_sessions 同族）。
3. **PlanCardView.tsx**：L48「拆除计划」→「方案摘要」；底线声明从卡片内部小字（L56）升级为头部常驻行；新增 CTA 按钮「在规范演进中展开 →」——props 加 `onOpenEvolution?: () => void`，App.tsx 接线 `goEvolution`。
4. **EvolutionView.tsx**：L437-441 副行与 L455 追问句保持「工件卡/工件流」（已 canonical，逐处核对）；ScenarioGuide 步骤②「约定冲突」→「惯例冲突」、步骤③「生成防误删推演卡与拆除清单」→「产出落位表、死代码清单与风险 Checklist；引擎只读，改动由你执行」；L357「变更清单」→「落位表·变更」；L445 输入 label 保留「演进意图」（动词族合法）。
5. **Sidebar.tsx**：L239 节标题 `Evolution`→「规范演进」；L248「演进推演工作台」→「规范演进」。
6. **Canvas.tsx 空态**：②改「**要方案 →**「规范演进」给改动意图，产出落位与风险清单（引擎只读）」+「**问现状 →**「架构问答」…」（两动词前置），其余四视图压一行；③示例句不动。
7. **DashboardView.tsx**：L111「提问」→「查调用链」。
