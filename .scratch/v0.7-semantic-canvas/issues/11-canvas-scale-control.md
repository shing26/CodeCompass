# 11: 画布规模控制（Max Hop 裁剪 + 高连接度聚合徽标）

Status: ready-for-agent

## 问题

被 15+ 组件复用的公共 API 展开时数十条连线挤压重叠（报告角色 2 痛点）。mermaid 增强层路线下不做真折叠，从数据源头控制图规模。

## 任务

1. Max Hop 上限：调用链/子图渲染前按 distance/hop 裁剪节点（默认上限 3，与后端 1~3 Hop 一致），被裁剪的节点聚合为单个 `… +N more` 汇总节点（无 code:// 绑定），图底部/工具栏提示"已聚合 N 个深层节点"。
2. 高连接度聚合：入度或出度 >10 的节点，其发散边默认收敛为徽标（`↔ 15 callers`，点击展开一次）。
3. 裁剪/聚合在前端渲染层实现（不改后端契约）；节点 search（issue 10）需能命中聚合内的节点并提示"位于聚合节点内，点击展开"。
4. 组件测试：超限图被裁剪且汇总节点出现；聚合徽标点击展开。

## 验收

- 构造 15-caller fixture：渲染节点数受控、徽标与提示正确、无 mermaid 语法错误。
