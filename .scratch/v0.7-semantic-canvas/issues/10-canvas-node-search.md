# 10: 画布节点搜索高亮定位

Status: ready-for-agent

## 问题

大图中定位具体节点只能肉眼扫描（报告角色 2 痛点：缺"画布内符号即时过滤搜索框"）。

## 任务

1. MermaidDiagram 工具栏增加搜索框（复用 Sidebar 搜索的 `/` 快捷键模式不冲突——画布内 Ctrl/Cmd+F 或图上固定输入框，落地时取简）。
2. 输入即对 SVG 节点文本（text/foreignObject）做不区分大小写包含匹配：命中节点加高亮 class（描边/底色，复用主题 accent），多命中显示 n/m 计数并支持 Enter/上下键循环。
3. 命中后配合 09 的 pan-zoom 将视口平移居中到该节点。
4. 无命中显示 0/0 弱提示；清空恢复。

## 验收

- 组件测试：输入命中节点高亮、计数正确、清空恢复；与 pan-zoom 联动不报错。
