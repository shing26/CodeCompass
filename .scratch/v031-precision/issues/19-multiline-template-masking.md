> 判据：HANDOFF §2.2「降低误报」——幻影声明是**假符号**，会污染 `index.types` 与一切按名查表的解析路径
> 波次：待排 ｜ 状态：**✅ 已落地（2026-09-24）** ｜ 依赖：票 18/20（同文件，已串行）

## 1. 缺陷（实测）

`TypeScriptAdapter.ts::maskLiteralsAndComments` 的 `'`/`"` 分支是**按行**的：

```js
/(["'`])(?:\\.|(?!\1)[^\\\n])*\1|\/\/[^\n]*|\/\*[\s\S]*?\*\//g
```

`[^\\\n]` 排除了换行，所以**多行模板串只被掩到第一个换行**，其后的内容按**源码**被扫描。后果是
`extractTypeOnlyDeclarations`（正则找 `interface X {`）把**模板串里的文字**当成真声明，产出**幻影符号**。

实测证据（本仓，2026-09-24）：

```
# 票 18 新加的单测 fixture（多行模板串）声明了 interface RepoContextValue { client: RepoQAClient }
# → 与真声明 apps/repoqa-web/src/client/... 内容不同 → 跨文件表的歧义规则（正确地）丢弃真表项
# → pickFolder 绑定失败 → 复测"看起来没用"
# 票 20 又踩一次：fixture 里的 class RepoQAClient { queryRepo(...) ... } 把真 class 的 queryRepo 从表里挤掉
```

幻影不止出现在测试里：**生产代码同样暴露**——`chat/agent.ts` 的系统提示词、`engine/repoqa-export.ts` 的导出模板
都是多行模板串，任何一段含 `interface Foo {` / `function bar(...)` 的文字都会变成符号或声明表条目。

## 2. 影响面（两个方向）

| 方向 | 后果 | 严重度 |
|---|---|---|
| 幻影**接口/类型**符号 | `index.types` 多出真实不存在的类型；按名查表可能命中幻影 → **假边** | 中 |
| 幻影**声明表**条目（票 18/20 的表） | 与真声明同名异内容 → 歧义规则丢弃真项 → 该仓跨文件定型**整体失效**（fail-closed，不造假边） | 中 |
| 符号计数/普查 | `type-declaration` 排除计数虚高，M2/桶统计被污染 | 低 |

**注意方向**：第二行是"沉默失效"——没有报错，只是精度变差，且**越是在测试/提示词写得多的仓库越容易触发**（本仓即中，两天内中两次）。

## 3. 为什么不能用"一行加宽 backtick 分支"修（重要，别重复踩）

一行加宽（`` `(?:\\.|[^\\`])*` `` 允许跨行）实测**坏得更厉害**：

> 掩码器自身的源码与注释里就有反引号。跨行匹配后，**注释里的反引号会与远处的反引号配对**，
> 使中间的真注释文字**不被掩码**。本仓 `TypeScriptAdapter.ts` 当场自伤：其注释里的
> `` `interface RepoContextValue { … }` `` 变成幻影声明（探针 `probe-mask.ts` 输出 `masked@29859 line=760`）。

即：**配对只有在注释已被排除之后才可信**——这是状态机问题，不是正则强度问题。

## 4. 落地：一趟扫描式掩码器

`maskLiteralsAndComments` 改为**单趟状态机**（`out = source.split('')`，同长空格替换，**偏移契约不变**）：

- `//`、`/* */`、`'…'`、`"…"`、`` `…` ``（**允许跨行**）、`/…/` 六类，逐类走各自的状态；
- 模板串处理 **`${ … }` 插值**与**插值内嵌套模板**（`endOfTemplate` 递归），并在 `$`/`{` 上计深度；
- 正则字面量靠"前一个有意义的字符"判定（`(,=:[!&|?{};+-*%~^<>` 或 `return`/`typeof`/`new`/… 之后才是正则，
  否则是除法），**遇换行即判非正则**（正则不能跨行），字符类 `[…]` 内的 `/` 不闭合；
- **已知边界（刻意保守，写进注释）**：`)`/`]` 之后的 `/` 一律当除法，于是 `if (x) /re/.test(y)` 这种
  紧跟在括号表达式后的正则语句不被掩码。两种错法都可能，而**少掩码只可能造幻影、多掩码会藏掉真代码**，故取前者。
