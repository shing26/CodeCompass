# Issue 16 — 模型在环一轮实验：自愈率 + 误调率（评估维 E-M5 2→3；E-M2 前向基线）

> 依据：短板清单 E-M5「错误信息是给 LLM 看的，那 LLM 到底看懂了吗」；E-M2 的 3 分要件是「描述质量的迭代记录（如误调率下降）」
> 分档要件（§2.1）：E-M5 3 分 = 有「模型遇错后自愈成功率」数字；E-M2 3 分 = 有描述质量迭代记录
> 波次：v0.31.0 ｜ 用户裁决：2026-09-21 批准（**一轮实验，约 20 次调用**）

## 口径（先定，防事后倒推）

- **E-M5 本轮可到 3 分**：产出「模型按 suggestion 自我修正后成功」的比例。
- **E-M2 本轮只到「前向基线」**：单轮实验只能给出误调率基线，**没有"下降"**（未做描述迭代 → 无法声称迭代记录）。
  报告与 CHANGELOG 必须如实标注：**E-M2 仍记 2 分**，不因有数字就宣称 3 分。
- 模型：`.env` 的 `REPOQA_LLM_MODEL` / `REPOQA_LLM_BASE` / `REPOQA_LLM_API_KEY`（仓内已配置）；调用量上限 **20 次**。

## 内容

新增 `scripts/eval/mcp_model_in_loop.mjs`（或 `.ts`，与仓内 eval 同栈），复用 `scripts/smoke/stub-llm.mjs` 之外的真实模型路径：

### (a) 误调率基线（E-M2 前向基线）

10 个任务：给模型 17 个工具的 name + description + inputSchema，要求它只输出"该调哪个工具 + 参数 JSON"（不真跑，零副作用）。
判定：选出正确工具 = 命中；参数键集与 schema 必填一致 = 参数正确。两个比例都记。
**产出**：误调率 = 1 − 命中率；参数错率。

### (b) 自愈成功率（E-M5 → 3 分）

10 个场景，每个分两步：
1. **制造结构化失败**：用真实 MCP 会话触发带 `suggestion`/`code` 的错误（来源见下），拿到错误载荷；
2. **让模型读错误载荷后重试**：把载荷原样交给模型，要求给出修正后的调用；再真跑一次 → 成功即"自愈成功"。

场景来源（仓内现成，无需造）：
- 参数类型/必填违规 → schema 拒绝 + 校验信息（票 07 的护栏）；
- `repo_indexing_conflict` / `repo_not_found` 等带 `code` 的失败；
- `plan_evolution` / `get_conventions` 的**约定冲突结构化载荷**（`module-evolution-engine.ts` 的 `suggestion` 字段族）。

**产出**：自愈成功率 + 逐场景明细（场景 / 首错 / 模型修正 / 是否成功）。

- [x] 无仓库副作用（工具选择只取意图不真跑；自愈只跑只读工具）
- [x] 模型不可用时拒绝运行（`isLlmConfigured` 守卫，实测干跑 `--budget 0` 正常收口）

**两条纠正（如实登记，见报告 §一/§二）**：

1. **首次调用未失败的场景必须剔除**：10 个自愈场景里 3 个的"首次调用"其实成功了（repoId 传仓库名被名称解析接受、trace/diagnose 对陌生符号仍返回载荷），按 10 个全算会得到虚高的 10/10。现以 MCP 的 `isError` 为权威判定 → **真失败 7 个，全部恢复 = 7/7**。
2. **E-M2 的 60% 不能当"描述质量差"的证据**：6 次选错里 5 次是选 `list_repos` —— 那正是票 07 写进 `instructions` 的"list_repos first"编排指令，属**指令污染**（测的是是否遵循工作流，不是描述区分度）。要拿 E-M2 的 3 分必须先改测量协议（剔除编排指令 / 两阶段协议），本轮不声称。

**实验后的 provider 状态（必须连着读）**：实验后收口门禁出现 2 条失败（incident / chat SSE），探测得 **HTTP 402（额度不足）**——非代码回归。CI 无 `.env`（无凭据）时 chat/incident 走确定性降级，最近 6 次 CI 全绿为证；即「无 LLM」「LLM 正常」两态都绿，只有「配了 key 但 402」红。额度是否被本轮 40 次调用耗尽**无法确定**（时间吻合，key 套餐上限亦属可能），**如实记录**。参见报告 §六；**门禁是否加 stub 回退属决策**，本批只登记不改。

## 风险

1. **小样本（10/10）**：比例本身置信区间很宽——报告必须标注 n=10，不得当作稳定指标引用。
2. 模型选择偏差：单一模型的结果不能推广到所有宿主模型；报告写明所用模型。
3. 花 token 的唯一一项：脚本内置上限（20 次）并先打印预计调用数再执行。
