# 11：移动端检查器抽屉关闭后，复点同文件节点永不可再开（QA-02）

## Agent Brief

**Category:** bug
**Summary:** 窄屏（≤375px 抽屉形态）下经遮罩关闭 Inspector 抽屉后，再次点击**同一文件**的图节点/卡片无法重新打开抽屉——只有换一个文件才恢复。

**Current behavior:**
抽屉的自动展开是「检查器当前文件」变化驱动的 effect：文件字符串不变则不再置 open。复现（QA 双次实测）：375px → 点 flow-card → 抽屉开 → 点 `inspector-mask` 关 → 复点同一/同文件另一卡 → 抽屉不再出现。桌面端（md+，抽屉类惰性）无此症状。

**Desired behavior:**
任何导航入口（拓扑节点、flow-card、anchor、命令面板、导览步骤）在窄屏下都能重新打开抽屉，即使目标与当前文件完全相同；桌面端行为不变。

**Key interfaces:**
- Inspector 域 context（提供 `inspectorOpen` 与文件导航 `openFile` 的那一片）——展开时机从「file 变化」改为「导航动作发生」：`openFile` 本身（或其调用点）显式置 open，不再仅靠 `[file]` effect
- 各导航调用点均经由同一 `openFile`/`onNavigate` 契约，修复应一处生效全路径覆盖

**Acceptance criteria:**
- [x] 375px：开抽屉 → 遮罩关 → **复点同一节点** → 抽屉重现（bounding rect 断言 left < 视口宽）
- [x] 同文件不同 symbol/行、不同文件、命令面板跳转路径均能开
- [x] 桌面（≥768px）行为与视觉零变化
- [x] web 全量测试绿（基线 272 起步，须含上述回归用例）

**Out of scope:**
- 侧栏抽屉同症状若存在则顺带核对，但交互重设计不做；Monaco 相关问题归 #12

## Comments

- 实现（2026-09-10）：`useInspector` 新增 `navSeq` 计数——每次 `openFile` 导航动作（含同文件复点）自增；`InspectorContext` 抽屉展开 effect 改为 `[inspector.file, inspector.navSeq]` 双依赖，时机从「file 变化」变为「导航动作发生」。所有导航入口（拓扑/flow-card/anchor/侧栏/导览/面板/反查 chips）共用 `openFile` 契约，一处生效全路径覆盖。桌面端 `md:` 类惰性不变，行为零变化。
