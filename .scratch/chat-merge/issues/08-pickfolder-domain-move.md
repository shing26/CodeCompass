## Agent Brief

**Category:** enhancement
**Summary:** 原生目录选择器的客户端方法挂错了域——`pickFolder()` 目前在 chat 子客户端命名空间下，实际服务的是仓库导入表单。

**Current behavior:**
调用链为 `App → TopBar → ImportRepoModal` 的浏览按钮经 `client.chat.pickFolder()` 发出 `GET /api/dialog/folder`。方法声明与 chat SSE/会话方法同居一处，域语义错位（目录选择属 ingestion 面）。

**Desired behavior:**
`pickFolder()` 成为根客户端（与 `previewRepo`/`cloneRepo` 同层）的方法，返回契约 `{ supported: boolean; canceled?: boolean; path?: string }` 不变；调用点不再出现 chat 命名空间。

**Key interfaces:**
- 根客户端类 — 新增 `pickFolder()`，形状不变
- chat 子客户端 — 移除该方法
- `ImportRepoModalProps.onPickFolder` — 签名不变

**Acceptance criteria:**
- [ ] `GET /api/dialog/folder` 仍由根客户端方法触达，响应契约零变化
- [ ] 全仓无 `chat.pickFolder` 引用残留
- [ ] 既有 TopBar/ImportRepoModal 组合测试通过；如有 mock 挂在 chat 子对象上，迁移 mock 形状而非删断言
- [ ] web 全量测试绿（基线 272 起步，允许新增）

**Out of scope:**
- 服务端 dialog 域任何改动；非 Windows 门控逻辑
