# Issue 05 — 空桶 nextAction 引导失效

> *This was generated by AI during triage.*

Status: bug / ready-for-agent

## 现象（复现仓库：lazygit，repoId `repo-609a7d6d-c824-4e93-81ef-fa52f3442af4`）

scan 的 deepChains 桶 `total: 0`、`items: []`，但 `nextAction` 仍返回：

> "Run codecompass_diagnose on an entry to see the layered chain."

没有 entry 可指——agent 跟随引导后会卡死或瞎猜。对 self-recommending 引擎（v0.20 缺口 2 的核心卖点）来说，空桶引导失效比没有引导更伤。

## 根因

`services/control-plane/src/scan-engine.ts` 的 `bucket()` / 各桶构造处：`nextAction` 是静态字符串，与 `items.length` 无关。

## 修复

- 空桶（`total === 0`）时 nextAction 置为不指向具体工具的说明，如 "No candidates found by this bucket's deterministic rules — nothing to act on."（措辞 agent 可定）。
- 或 payload 允许 nextAction 为空——若是契约变更（`packages/contracts` 三处镜像类型 + gate 断言），按并行协作约定先落 spec；推荐保持字段恒存在、仅改文案，零契约变更。
- 补 `scan-engine.test.ts`：空桶断言 nextAction 不含 "Run codecompass_" 字样。

## 验收

- lazygit 重跑 scan：deepChains 空桶 nextAction 不再引导到 diagnose；非空桶引导不变；单测/e2e 全绿。
